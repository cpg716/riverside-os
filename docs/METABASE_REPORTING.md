# Metabase reporting (retired)

Metabase is no longer part of the Riverside OS reporting runtime. The iframe, proxy, separate login, shared credentials, metadata-refresh scripts, application database, and Compose services were replaced by the native **ROSIE Insights** workspace.

Use **[CUBE_INSIGHTS_REPORTING.md](CUBE_INSIGHTS_REPORTING.md)** for the current embedded architecture, governed read-only query path, APIs, favorites, automatic report history, 180-day archive behavior, CSV export, and printing.

This filename remains only so older release notes and operational records do not become broken links. Do not use it as a setup guide.
