  pickup evidence. Completed takeaway sales retain the standard sale receipt;

  while Add Customer is open.

## Operational boundary

Passing source and GitHub publication gates does not prove that a production
Main Hub installed the build. Production signoff still requires the installed
version and SHA, `/api/ready`, database-backed lookup, workers/dependencies, and
`/api/health`, followed by Register, printer, payment-terminal, backup, and
store-workflow checks on the physical environment.
